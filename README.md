# L_Shop — ЛР15-16 (финальная доработка)

Этот `README` описывает запуск и проверку проекта для ветки с доработками по ТЗ `ЛР15-16_Финал_Шопа.pdf`.

## Стек

- **Backend:** Node.js, Express, TypeScript  
- **Frontend:** React, Vite, TypeScript  
- **Тесты backend:** Jest + Supertest

## Что реализовано по ТЗ

### 1) Локализация (сессионная)
- Добавлен второй язык (белорусский).
- Есть всплывающая плашка выбора языка по стране/локали.
- Язык хранится в сессионной cookie (`locale`), без долгоживущего хранения.

### 2) Система рекомендаций
- На товарах используются скрытые теги.
- При лайке теги добавляются в профиль рекомендаций пользователя.
- Рекомендации встраиваются в ленту.
- Реализовано затухание веса рекомендаций со временем.

### 3) Роли и админ-управление товарами
- Добавлена роль `owner` (и поддержка `manager` в API).
- Реализована админ-страница создания/редактирования товаров.
- Есть role-check middleware и TTL для owner-сессии.

### 4) Оценки и комментарии
- Пользователь может оставить комментарий и оценку товару.
- Отображается средняя оценка и дата комментария.
- Комментарии/оценки доступны только авторизованным пользователям.

### 5) Тесты (обязательная часть)
- API-точки покрыты тестами через Supertest.
- Утилиты и независимые функции покрыты через Jest.
- Есть smoke-набор для auth/catalog/cart.

## Что не реализовано (необязательное, ⭐)

- Frontend e2e/integration (Cypress/Playwright) — не добавлялись.
- CI/CD — не добавлялось.

## Структура запуска

Проект состоит из двух приложений:

- `server` — backend API (порт `3000`)
- `client` — frontend (порт `5173`)

## Установка зависимостей

Из корня проекта:

```bash
cd server
npm install

cd ../client
npm install
```

## Запуск проекта

### 1. Запуск backend

```bash
cd server
npm run dev
```

Backend поднимается на: `http://localhost:3000`

### 2. Запуск frontend

В отдельном терминале:

```bash
cd client
npm run dev
```

Frontend поднимается на: `http://localhost:5173`

## Запуск тестов

```bash
cd server
npm test
```

Для watch-режима:

```bash
npm run test:watch
```

## Учетные данные владельца (owner)

- **Логин:** `owner@com`
- **Пароль:** `owner@com`

Вход в админку: `http://localhost:5173/admin`

## Короткий чек-лист проверки

1. **Локализация:** открыть сайт, выбрать язык в плашке, проверить смену текста.
2. **Рекомендации:** авторизоваться, ставить лайки в рекомендованной витрине, проверить блок рекомендаций.
3. **Админка:** зайти на `/admin` как owner, создать/обновить товар, проверить отображение в каталоге.
4. **Отзывы:** оставить оценку/комментарий, проверить средний рейтинг и дату.
5. **Тесты:** запустить `npm test` в `server`, убедиться что все тесты проходят.
